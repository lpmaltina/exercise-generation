# Генерация упражнений для изучения иностранного языка с помощью LLM

Как запустить эксперимент по оцениванию?

```python evaluate_with_deepseek.py <путь к файлу со сгенерированным упражнением> <путь к файлу с сырыми результатами оценивания>```

```python parse_evaluations.py <путь к файлу с сырыми результатами оцененивания> <путь к файлу со структурированными результатами оценивания>```
