# Генерация упражнений для изучения иностранного языка с помощью LLM

Как запустить эксперимент?

1) Сгенерировать конфигурации упражнений:

```python create_configs.py```

2) Сгенерировать упражнения:

```python generate.py```

3) Выполнить оценивание качества сгенерированных упражнений:

```python LLM_evaluate.py <путь к файлу со сгенерированными упражнениями> <путь к файлу с сырыми результатами оценивания>```

```python parse_evaluations.py <путь к файлу со сгенерированными упражнениями> <путь к файлу с сырыми результатами оценивания> <путь к файлу со структурированными результатами оценивания>```

4) Сформировать таблицу с результатами и построить графики:

```python analyze_results.py```
