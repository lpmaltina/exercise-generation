# Генерация упражнений для изучения иностранного языка с помощью LLM

Как запустить эксперимент по оцениванию?

```python LLM_evaluate.py <путь к файлу со сгенерированным упражнением> <путь к файлу с сырыми результатами оценивания>```

```python parse_evaluations.py <путь к файлу со сгенерированными упражнениями> <путь к файлу с сырыми результатами оцененивания> <путь к файлу со структурированными результатами оценивания>```
