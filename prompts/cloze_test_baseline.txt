Create a cloze test for learning English. 
The task should contain {n_questions} fill-in-the-blank items based on the text: {text}
The text should provide sufficient context to deduce the correct missing word. Leave at least 5 words between any two gaps.
If several (2-3) equally valid answers exist for a gap, include them all in the correct_answers array. Do this only if the variants are fully interchangeable without changing meaning.
Return a valid JSON of the following structure:
{
    "text_with_gaps": "<text with (<gap id>) _____ replacing the missing words>",
    "gaps": [
    {
        "id": <gap id>,
        "correct_answers": ["<the missing word>", "<another correct variant>", ...],
    }
    ...
    ]
}
Gap ids start from 1 and increase sequentially.
