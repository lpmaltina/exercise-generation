Create a vocabulary wordbank test for learning English. Follow these steps, showing your reasoning for each step before proceeding to the next.

Step 1. Read the text: {text}
- Identify all content words (nouns, main verbs, adjectives, adverbs) in the text.
- Determine the text's CEFR level based on vocabulary and sentence complexity.
- Note which content words are likely target vocabulary for that level.

Step 2. Select {n_gaps} words to blank out:
- Target content words that are likely target vocabulary for the text's CEFR level.

Step 3. Check the answers:
- For each wordbank word, think: "Can I guess the answer from grammar rules alone?". If yes, discard that gap and select a different word from the text.
- For each wordbank word, think: "Could this word correctly fill any other gap?" If yes, discard one of the conflicting gaps and select a different word.
- Every word in the wordbank must be the uniquely correct answer for its gap and incorrect for all other gaps.

Step 4. Construct the text_with_gaps and wordbank:
- Replace each chosen word with the placeholder "(<gap number>) _____".
- Gap ids start from 1 and increase sequentially.
- Sort the wordbank in alphabetical order.
