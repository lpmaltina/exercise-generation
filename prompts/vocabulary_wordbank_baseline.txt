Create a vocabulary wordbank test for learning English.
Provide a wordbank containing all correct answers. The wordbank should contain {n_gaps} words and be output in alphabetical order. 
Target only content words for the blanks (nouns, main verbs, adjectives, adverbs). The answers should not be guessable from grammar rules alone.
Every word in the wordbank must be the uniquely correct answer for its gap and incorrect for all other gaps.
Blank out words that are likely target vocabulary for the text's CEFR level.
Create the task based on the text: {text}
Return a valid JSON of the following structure:
{
    "text_with_gaps": "<text with (<gap id>) _____ replacing the missing words>",
    "wordbank": ["<word 1>", "<word 2>", ...],
    "gaps": [
    {
        "id": <gap id>,
        "correct_answer": "<correct answer>"
    }
    ...
    ]
}
Gap ids start from 1 and increase sequentially.
