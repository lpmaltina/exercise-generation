Evaluate the reading comprehension exercise using the following criteria.

Text: 
{text}

Questions: 
{questions}

Use the scale from 1 to 5, where 1 is very poor and 5 is excellent.

Part 1. Evaluate the text.

- Matching the Topic. Does the text match the topic "{topic}"?
1: The text is completely unrelated to the topic.
2: The text is loosely related to the topic but mostly about something else.
3: The text is partially about the topic but drifts off-topic significantly.
4: The text is clearly about the topic with only minor digressions.
5: The text fully matches the topic. 

- Logic & Commonsense. Is the text logical and consistent with commonsense?
1: The text has four or more logical errors.
2: The text has three logical errors.
3: The text has two logical errors.
4: The text has one logical error.
5: The text is logical and consistent with commonsense.

- Vocabulary & Grammar. Is the text grammatically correct and well-worded?
1: The text contains four or more grammar, vocabulary, spelling errors or very unnatural wordings.
2: The text contains three grammar, vocabulary, spelling errors or very unnatural wordings.
3: The text contains two grammar, vocabulary, spelling errors or very unnatural wordings.
4: The text contains one grammar, vocabulary, spelling error or very unnatural wording.
5: The text contains no grammar, vocabulary, spelling errors or very unnatural wordings.

Part 2. Evaluate the questions.

a) Evaluate each question using the following criteria.

- Logic & Commonsense. Are the question and the answer options logical and consistent with commonsense?
1: The question is not reasonable and contains serious logical flaws.
2: The question is reasonable, but all answer options are clearly wrong from the point of commonsense.
3: The question is reasonable, but some answer options are clearly wrong from the point of commonsense.
4: The question is reasonable, but one answer option is clearly wrong from the point of commonsense.
5: Both the question and the answer options are logical and consistent with commonsense.

- Vocabulary & Grammar. Are the question and the answer options grammatically correct and well-worded?
1: The question and answer options contain four or more grammar, vocabulary, spelling errors or very unnatural wordings.
2: The question and answer options contain three grammar, vocabulary, spelling errors or very unnatural wordings.
3: The question and answer options contain two grammar, vocabulary, spelling errors or very unnatural wordings.
4: The question and answer options contain one grammar, vocabulary, spelling error or very unnatural wording.
5: The question and answer options contain no grammar, vocabulary, spelling errors or very unnatural wordings.

- Text-Based Answerability. Can the question be answered using only the information provided in the text?
1: The answer is not found in the text at all.
2: The answer is mostly not supported by the text; substantial outside knowledge or guessing is required.
3: The answer is partially supported by the text, but some outside inference is needed.
4: The answer is largely present in the text, but some indirect inference is still needed.
5: The answer is fully present in the text, or directly inferred from it.

- Reading Dependency. How difficult would it be to guess the correct answer without reading the text?
1: The correct answer is easily guessable using only general knowledge.
2: The correct answer is guessable using general knowledge, though the text provides some helpful specifics.
3: The correct answer is possibly guessable using general knowledge, but the text narrows it down significantly.
4: The correct answer is difficult to guess without reading the text; general knowledge helps only slightly.
5: The correct answer is difficult to guess without reading the text; general knowledge does not help.

- Answer Unambiguity. Is exactly one answer unambiguously correct based on the text?
1: Multiple answers are correct, or the intended "correct" answer is contradicted by the text.
2: Two answers can be considered correct, though the evidence for the intended answer is slightly stronger.
3: One answer is clearly intended as correct, but another option can be considered partially correct.
4: One answer is clearly correct, with only a far-fetched argument possible for another option.
5: Exactly one answer is unambiguously correct.

- Distractor Plausibility. Are all incorrect options believable to someone who has read the text but not fully understood it?
1: All incorrect options are obviously wrong.
2: Most incorrect options are obviously wrong.
3: Some incorrect options are obviously wrong, but others are plausible.
4: Most incorrect options are plausible.
5: All incorrect options are plausible.

- Using Paraphrases. Does the correct answer rephrase the text rather than copy it verbatim, while expressing the same meaning? Some shared key words are acceptable.
1: The correct answer expresses a meaning different from the text.
2: The correct answer copies the text verbatim.
3: The correct answer changes just one or two words, while expressing the same meaning. Stronger paraphrase is possible.
4: The correct answer changes more than two words, while expressing the same meaning. Stronger paraphrase is possible.
5: The correct answer strongly rephrases the text, while expressing the same meaning. Some shared key words are acceptable.

- Explanation Quality. Does the explanation accurately describe why the correct answer is right and why the distractors are wrong?
1: No explanation is provided (the explanation just repeats the correct answer) or it says that a wrong answer is correct.
2: The explanation contains factual contradictions.
3: The explanation accurately describes why the correct answer is right, but does not show why the distractors are wrong OR the explanation accurately describes why all distractors are wrong, but does not show why the correct answer is right.
4: The explanation accurately describes why the correct answer is right, but shows only why some - but not all - distractors are wrong.
5: The explanation accurately describes why the correct answer is right and why all distractors are wrong.

b) Evaluate the questions overall using the following criteria.
- Text coverage. Do the questions cover different parts of the text and are not concentrated in one part?
1: All or most questions target the same part of the text.
2: Questions mostly cluster in one part, with only brief mention of other parts.
3: Questions cover different parts of the text, but one part is overrepresented or another neglected.
4: Questions are well distributed across the text, with only minor imbalance.
5: Questions are evenly distributed across the text, covering different ideas.
